# 📊 Retail Sales Dashboard

An interactive Retail Sales Dashboard built using **Python, Pandas, Streamlit, and Plotly** to analyze sales performance, profitability, product categories, and regional sales.

## 🚀 Live Demo

**Live Dashboard:** [Add your Streamlit Cloud URL here]

## 📌 Project Overview

This project analyzes retail sales data to identify business trends and performance insights.

The dashboard allows users to interact with the dataset using date and category filters and explore important sales metrics through interactive visualizations.

## 📂 Dataset

The project uses a Superstore retail sales dataset containing information about:

- Order Date
- Order ID
- Customer Name
- Product Category
- Sales
- Profit
- Quantity
- Region

## 📈 Dashboard Features

### 1. Interactive Filters
- Start Date and End Date filters
- Product Category filter

### 2. Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Average Order Value

### 3. Data Visualizations
- Monthly Sales Trend – Line Chart
- Sales by Category – Bar Chart
- Sales by Region – Donut Chart

### 4. Additional Features
- Expandable sales dataset
- Filtered data table
- CSV download functionality
- Interactive charts

## ⚙️ Installation and Setup

### Step 1: Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the project folder

```bash
cd Retail-Sales-Dashboard
```

### Step 3: Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the application

```bash
python -m streamlit run app.py
```

The dashboard will open at:

`http://localhost:8501`

## ☁️ Deployment

This application is deployed using Streamlit Community Cloud.

1. Upload the project to GitHub.
2. Connect your GitHub repository to Streamlit Community Cloud.
3. Select `app.py` as the main application file.
4. Click Deploy.
5. Add the deployed application URL to this README.
